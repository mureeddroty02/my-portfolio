HOW TO USE
1. Put your photos in the images/ folder using EXACTLY these names:
   profile.jpg          (your portrait, square works best)
   project-shina.jpg    (Shina translator project)
   project-face.jpg     (face attendance project)
   project-mobile.jpg   (Java mobile app project)
   Until a file exists, the demo placeholder shows automatically.
2. Put your resume in this folder named resume.pdf (for the Download CV button).
3. Open index.html in a browser to preview.
4. Publish free: create a GitHub repo named yourusername.github.io, upload ALL
   files and the images folder, then Settings > Pages > Deploy from main branch.
